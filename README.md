# Besay Portfolio

Готовая версия портфолио для GitHub Pages и вставки в Tilda через iframe.

## Что загружать в GitHub

Загрузите папку `portfolio` в корень репозитория `besay`.

## Код для Tilda

Код для блока T123 лежит в файле:

`portfolio/tilda-iframe-code.html`

## Структура материалов

Папки `sections/*/materials/` оставлены для изображений, превью, исходников и документов по каждому направлению портфолио.


Обновление: добавлена защита условий desktop/mobile и авто-высота iframe для нормального скролла в Tilda.
