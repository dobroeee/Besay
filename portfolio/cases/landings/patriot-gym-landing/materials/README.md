# Материалы кейса Patriot Gym

Сюда добавляются изображения и скриншоты для страницы кейса.

## Структура папок

- `01-hero/` — главный экран лендинга на десктопе.
- `02-full-page/` — длинный скрин всей страницы или общий мокап лендинга.
- `03-schedule/` — скрин расписания на сайте и скрин таблицы для редактирования.
- `04-analytics/` — скрины Яндекс Метрики, целей, заявок, источников трафика.
- `05-design/` — детали дизайна: цвета, типографика, UI-блоки.
- `06-mobile/` — скрины мобильной версии.
- `07-og-cover/` — обложка для соцсетей и превью.
