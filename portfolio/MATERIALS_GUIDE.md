# Как хранить материалы

Для каждого направления используй свою папку:

- `sections/about/materials/`
- `sections/sites/materials/`
- `sections/brandbooks/materials/`
- `sections/custom/materials/`
- `sections/mailings/materials/`
- `sections/social/materials/`

Пример ссылки на превью сайта:

```html
<img src="./sections/sites/materials/previews/patriot-gym.webp" alt="">
```

Пример ссылки на изображение рассылки:

```html
<img src="./sections/mailings/materials/images/estetik-shop.webp" alt="">
```

Файлы лучше называть латиницей без пробелов:

```text
patriot-gym.webp
bb-mgok-cover.webp
estetik-shop-email.jpg
```
