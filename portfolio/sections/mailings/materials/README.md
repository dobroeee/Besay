# Материалы раздела mailings

Сюда загружай файлы для этого направления.

Рекомендуемая логика:
- `images/` — основные изображения и фотографии;
- `previews/` — превью для карточек;
- `source/` — исходники, макеты, дополнительные файлы;
- `documents/` — PDF, презентации, документы.

Для ссылки внутри HTML используй относительный путь, например:

```html
<img src="./sections/mailings/materials/previews/file-name.webp" alt="">
```
